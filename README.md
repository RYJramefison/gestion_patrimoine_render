# 💼 Gestion Patrimoine

Bienvenue dans le projet **Gestion Patrimoine**
Cette application permet de **suivre le patrimoine d'une ou plusieurs personnes** : biens (ordinateur, voiture…), revenus, dépenses et autres éléments financiers. L’idée est simple : enregistrer, consulter et mettre à jour ce que chaque personne possède, et garder un historique clair de toutes les possessions.

Imaginez une application où vous pouvez noter ce que possède chaque personne, voir l’historique et mettre à jour les fiches quand quelque chose change. C’est utile pour suivre un budget personnel, observer la valeur d’un bien au fil du temps, ou simplement tenir un inventaire financier clair et accessible.

Avec ce projet, vous pouvez :
- Consulter toutes les possessions enregistrées (liste complète)
- Rechercher une possession par son nom
- Lister toutes les personnes enregistrées
- Ajouter une nouvelle possession pour une personne
- Modifier une possession existante (changer le libellé, la date de fin, etc.)
- Fermer une possession (marquer qu’elle n’est plus active)
- Supprimer une possession

Toutes ces actions sont disponibles via **une API (service web)** et **une interface utilisateur (UI) en React**.
